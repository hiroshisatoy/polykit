Chrome Web Store 申請用の権限説明案。公開前に提出パッケージと照合してください。

・storage
画面の日本語表示設定を chrome.storage.local に保存し、ポップアップと翻訳ページで共有します。インストール・更新バージョンを chrome.storage.session に保持し、更新案内に使用します。

・ホスト権限 *://translate.wordpress.org/*
翻訳画面の原文、訳文、用語、状態を参照し、チェック、既存訳の参照、レビュー操作、表示補助を追加します。用語集や Consistency の情報も取得します。保存・承認はサイト上の利用者権限に従います。

・activeTab
ポップアップは現在のタブを取得して対応サイトか判定し、設定の反映先を決めます。ただし、対象ホスト権限だけで現在の URL を取得できる可能性があり、activeTab 権限そのものの必要性は未確認です。最小権限の観点から申請前に検証します。

・リモートコード
スクリプトと辞書は拡張機能に同梱されています。外部 HTML は情報として解析し、外部 JavaScript の取得・実行はソースの静的確認では見つかりませんでした。提出用 ZIP でも再確認してから申告します。
